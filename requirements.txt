# RTX 5090 / Blackwell (sm_120) needs torch >= 2.7 built for CUDA 12.8. The
# Dockerfile base (pytorch/pytorch:2.8.0-cuda12.8-cudnn9-devel) already
# satisfies this; on a stock RunPod template pick a "PyTorch 2.7+/CUDA 12.8"
# one so pip doesn't try to pull a mismatched wheel over it.

# --no-deps and satisfy protobuf here with a version wandb also accepts.
protobuf>=5,<6

# Experiment tracking. train.py imports it lazily (only needed when
# `wandb: true` in the config). Run `wandb login` once per pod.
